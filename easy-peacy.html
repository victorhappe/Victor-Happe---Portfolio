ET Emergency

Project overview

ET Emergency was an interactive website project where I developed a fictional emergency site about what to do if you are abducted by aliens.

The project focused on user interface development, visual identity and interactive elements. I worked with CSS, JavaScript and Adobe Illustrator to create a more dynamic and atmospheric digital experience.

I created sketches, moodboards, style tiles and an illustrated SVG character that could function as a visual UI element on the website.

For my portfolio, this project shows my ability to create a concept with a clear mood, visual direction and playful interaction.

Process and learning

In this project, I explored how CSS and visual styling can be used to create a strong atmosphere and make a website feel more personal and concept-driven.

I chose a dark, mysterious and slightly humorous alien theme to support the fictional emergency concept. The visual style was developed through moodboards, sketches and design experiments.

A key part of the project was working in Adobe Illustrator, where I created an interactive character and learned how SVG graphics can be exported and used directly in a website.

I also worked with UI elements such as pop-ups, dark mode, custom properties, transitions and simple JavaScript interactions.

This project helped me understand how interaction, illustration and visual storytelling can work together to create a more engaging user experience.
